# キャンプ道具の十年

十年後の価値から、キャンプ道具を選ぶ。

長く使える構造、修理性、交換部品、中古市場での残価を同じ基準で検証するキャンプギア専門メディアです。

## 編集原則

- 人気や広告報酬だけで順位を決めない
- 「十年使える」を保証表現にしない
- 価格・中古相場・修理情報には確認日と根拠を持たせる
- 未確認の残価率や耐久年数を創作しない
- 長期指数 / 修理指数 / 残価率を分けて表示する

## 技術方針

- Astro / Static First / Zero-JS by default
- Mobile First
- Content Collectionsで反復コンテンツを構造化
- `npm run check` と `npm run build` を完了条件に含める
