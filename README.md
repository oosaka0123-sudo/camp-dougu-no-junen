# キャンプ道具の十年

流行ではなく、売れ続けた時間で選ぶ。

発売から何年選ばれ続けているかを最初に確認し、その上で修理性、交換部品、中古市場での残価を検証するキャンプギア専門メディアです。

## ロングセラー判定

- 十年定番: 発売・系譜を確認でき、10年以上継続して選ばれているもの
- 定番候補: 5〜9年の継続実績を確認できるもの
- 観察中: 5年未満、または発売年・継続年数の確認が不十分なもの
- 発売年を確認できない場合は、推測で「ロングセラー」と呼ばない

## 編集原則

- ロングセラー歴を最初の評価軸にする
- 人気や広告報酬だけで順位を決めない
- 「十年使える」を保証表現にしない
- 価格・中古相場・修理情報には確認日と根拠を持たせる
- 未確認の残価率や耐久年数を創作しない
- ロングセラー歴 / 修理指数 / 残価率を分けて表示する

## 技術方針

- Astro / Static First / Zero-JS by default
- Mobile First
- Content Collectionsで反復コンテンツを構造化
- `npm run check` と `npm run build` を完了条件に含める
